# ساخت APK محاسبه‌گر مستمری (فارسی)

این پروژه برای ساخت ابری APK با GitHub Actions آماده شده است. خود این ZIP هنوز APK نیست؛ پس از بارگذاری در GitHub و اجرای Workflow، فایل نصب تولید می‌شود.

## ساخت APK بدون نصب ابزار روی رایانه یا گوشی

1. وارد https://github.com شوید و وارد حساب خود شوید (اگر حساب ندارید، رایگان بسازید).
2. با دکمه **New repository** یک مخزن جدید بسازید؛ نام پیشنهادی `pension-calculator-android` و حالت **Public** برای ساده‌تر بودن دسترسی به Actions. گزینه Add README را فعال نکنید.
3. فایل ZIP این پروژه را در رایانه باز کنید. در صفحه مخزن GitHub از **Add file → Upload files** استفاده کنید و تمام فایل‌ها و پوشه‌های داخل ZIP را بارگذاری کنید؛ پوشه مخفی `.github` و فایل `.github/workflows/build-apk.yml` حتماً باید بارگذاری شود. سپس **Commit changes** را بزنید.
4. در مخزن، زبانه **Actions** را باز کنید. اگر پیامی برای فعال‌کردن Actions دیدید، آن را فعال کنید.
5. در فهرست سمت چپ، **Build Android APK** را انتخاب کنید، سپس **Run workflow → Run workflow** را بزنید.
6. صبر کنید تا اجرای workflow سبز شود. وارد اجرای موفق شوید و پایین صفحه در بخش **Artifacts** روی `pension-calculator-debug-apk` بزنید تا ZIP خروجی را دانلود کنید.
7. ZIP خروجی را باز کنید و فایل `app-debug.apk` را استخراج کنید. آن را به گوشی منتقل و باز کنید. اگر اندروید اجازه نصب نداد، فقط برای برنامه‌ای که فایل را با آن باز می‌کنید گزینه **Allow from this source / اجازه از این منبع** را فعال کنید. پس از نصب، در صورت تمایل این اجازه را دوباره خاموش کنید.

## نکات مهم
- GitHub Actions APK را در فضای ابری می‌سازد؛ نیازی به Android Studio نیست.
- هر بار که کد تغییر کند، می‌توان workflow را دوباره اجرا کرد. Artifact این workflow تا ۱۴ روز نگه داشته می‌شود.
- اطلاعات پرونده‌ها در فضای ذخیره‌سازی محلی برنامه/مرورگر نگه‌داری می‌شود. با پاک‌کردن داده‌های برنامه یا حذف آن ممکن است سوابق پاک شوند؛ از دکمه «پشتیبان JSON» استفاده کنید.
- این APK نسخه شخصی و آزمایشی است. فرمول‌های مستمری بر اساس فرض‌های نسخه اولیه‌اند و برای تصمیم رسمی باید با صندوق/منابع انسانی تطبیق داده شوند.
- تاریخ‌های این نسخه باید به میلادی وارد شوند؛ تقویم شمسی گرافیکی هنوز افزوده نشده است.
